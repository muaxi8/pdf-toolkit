未指定 PDF 文件

在左上角输入文件路径回车；或点「上传 PDF」选文件；
也可以直接把 PDF 文件拖到这个窗口里。
打开后：浏览模式下点击对象可选中（拖动 = 移动，Delete = 删除）；
签名/涂鸦在页面上按住鼠标画；右侧边栏可拆分、合并。

浏览 / 选择

点击页面上已放置的签名 / 涂鸦 / 文字可选中它，然后：
• 按住拖动 = 移动位置（松手落定）
• 按 Delete 或下面按钮 = 删除

放置文字

先到页面上点一下放置位置。

手写签名

在页面上按住鼠标写名字（可多笔）。
日期自动取当天（本机）。应用后可回「浏览」模式拖动、删除。

涂鸦 / 批注

在页面上按住鼠标随手画（箭头、圈注……）。
